Quick diagnostics

Launcher will not start?

VELTRIX 0.8.2 writes startup diagnostics to your LocalAppData folder.

%LOCALAPPDATA%\VELTRIX\logs\launcher-startup.log
%LOCALAPPDATA%\VELTRIX\logs\launcher-startup-error.log

If the launcher fails, these are the first files to check.

01

Startup problems

Close VELTRIX completely, reopen it, then check the startup logs above. If the installer is blocked by Windows SmartScreen, choose the Windows option to run the unsigned app only if you trust the file you downloaded from this official page.

02

Microsoft login

VELTRIX uses the official Microsoft OAuth flow. A Minecraft Services Invalid app registration / 403 response is separate from your password and remains dependent on the VELTRIX app registration being approved.

03

Downloads

Windows is currently the supported public download. macOS and Linux are intentionally shown as Coming Soon and are not active download buttons yet.

FAQ

Why does Microsoft login return 403?

The launcher can complete the Microsoft/Xbox authentication flow, but Minecraft Services can reject the application registration until the VELTRIX app is approved. This should not be bypassed with another application's client ID.

Where are VELTRIX startup logs?

%LOCALAPPDATA%\VELTRIX\logs\

Is macOS or Linux available?

Not yet. Both platforms are displayed as Coming Soon.

Does VELTRIX store my Microsoft password?

No. VELTRIX is designed around the official OAuth login flow and does not ask you to type your Microsoft password into the launcher itself.
