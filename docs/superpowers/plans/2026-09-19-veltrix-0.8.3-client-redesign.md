# VELTRIX 0.8.3 Client Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Windows-only VELTRIX Client 0.8.3 installer whose launcher UI is completely restyled around the approved cyan-left / purple-right VELTRIX identity and supplied V logo, while preserving the existing Microsoft/Minecraft authentication and launch core.

**Architecture:** Reconstruct the known-good 0.8.2 launcher in the existing Windows packaging workflow, compile the 0.8.3 UI/branding changes against that known-good JAR, and apply the compiled 0.8.3 patch last. Keep editable UI source in the execution worktree only; the public repository keeps the compiled patch, installer-specific logo asset, contract tests, workflow, and release output. Website files are not part of this implementation.

**Tech Stack:** Java 21, Swing/AWT, `javac`, `jar`, `jpackage`, PowerShell, Bash contract tests, GitHub Actions `windows-latest`, WiX, ImageMagick.

**Spec:** `docs/superpowers/specs/2026-09-19-veltrix-0.8.3-redesign-design.md`

## Global Constraints

- Release version is exactly `0.8.3`.
- Output installer is exactly `VELTRIX-Setup-0.8.3.exe`.
- Website files are out of scope: do not modify `index.html`, `style.css`, `script.js`, `news.json`, `privacy.html`, or Pages design assets.
- Base palette is black / anthracite / dark metal.
- Left-side accent family is cyan / ice blue.
- Right-side accent family is violet / purple.
- Use the supplied cyan/lila V logo consistently in launcher, startup/loading screen, installer icon, desktop shortcut, and Start Menu shortcut.
- Preserve Microsoft OAuth PKCE, Xbox Live, XSTS, Minecraft Services, ownership checks, Minecraft profile retrieval, Minecraft launch coordinator, Fabric support, version manifest handling, Java runtime detection, and 0.8.2 startup diagnostics.
- Do not bypass the Minecraft Services `Invalid app registration` / allowlisting state.
- Support opens `https://discord.gg/9qYaVP6jvp`.
- Keep `jdk.crypto.ec` in the packaged Java runtime.
- Do not publish the editable launcher source as part of the public download or final release asset.

## Review Focus

1. **Small displays / resized window:** launcher must remain usable at the 1280×760 minimum without clipped PLAY, account, or navigation controls.
2. **Missing/invalid branding resource:** launcher must still start with a text/fallback icon instead of crashing before the UI appears.
3. **Unauthenticated / approval-required account state:** redesigned Home and Account surfaces must show the existing real state and never display a fake username.
4. **Support URL failure / Desktop API unavailable:** Support must show the Discord URL to the user instead of crashing the launcher.
5. **Corrupt persisted settings:** the 0.8.2 malformed-properties recovery and LocalAppData startup logging must still pass after the UI patch is applied.
