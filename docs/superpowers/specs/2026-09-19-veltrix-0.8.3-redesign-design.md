# VELTRIX 0.8.3 Redesign – Design Specification

## Status
Approved visual direction. Implementation has not started from this spec yet.

## Goal
VELTRIX 0.8.3 is the official visual redesign release. The launcher keeps the existing Microsoft authentication, Minecraft launch, version, Fabric, Java runtime, and startup-resilience logic, while replacing the current visual system with a new VELTRIX identity centered on the supplied cyan/lila V logo.

## Release identity
- Product name: VELTRIX Client
- Release version: 0.8.3
- Primary visual identity: split cyan/lila VELTRIX logo supplied by the user
- Base palette: black, anthracite, dark metal
- Left-side accent family: cyan / ice blue
- Right-side accent family: violet / purple
- Center transition: controlled blended glow; no rainbow styling
- Overall feel: premium 2026 gaming launcher, dark, clean, metallic, cinematic, not a generic Java desktop UI

## Visual system
### Color model
The interface uses a directional split-theme:
- left edges, left glows, left navigation emphasis: cyan
- right edges, right glows, right callouts: purple
- cards and large surfaces remain dark to avoid oversaturation
- important focus states may blend cyan into purple across borders or shadows

### Logo usage
The supplied V logo becomes the primary branding asset for:
- launcher navigation/header
- launcher startup/loading screen
- Windows installer icon
- desktop shortcut icon
- Start Menu icon
- website header and download section
- website launcher preview

The logo must be used consistently without replacing it with an older cyan-only V.

## Launcher layout
### Window shell
- dark frameless or custom-styled desktop window
- custom title bar and window controls matching the new theme
- minimum target desktop layout around 1280×760, optimized for 16:9 and 16:10 screens
- rounded dark panels with restrained cyan/lila edge lighting

### Navigation
Primary navigation remains:
- Home
- Versions
- Mods
- Settings
- Account
- Shop
- News
- Support

Navigation design:
- left-side vertical rail
- new V logo at top
- active entry receives cyan emphasis with subtle purple secondary glow
- inactive entries remain clean and low-contrast
- no oversized decorative UI that reduces usable content space

### Home / Play view
The Home view is the flagship screen.

Required composition:
- strong VELTRIX hero area
- title: `ONE CLIENT. MANY VERSIONS.`
- subtitle: `Play any version. Add your mods. Make it yours.`
- large PLAY button
- account status panel
- Minecraft version, mod loader, Java, and compatibility cards
- store/cosmetics preview strip

Visual behavior:
- hero atmosphere transitions from cyan on the left to violet on the right
- PLAY button uses the split-theme without becoming overly bright
- current real Minecraft profile name is shown after successful sign-in
- no fake hard-coded username in production UI

### Versions
- preserve existing version logic
- redesign selectors and version cards to match the new dark split-theme
- compatibility and loader information remain easy to scan
- supported/beta/unsupported states still use meaningful semantic colors, but within the VELTRIX visual system

### Mods
- preserve existing mod functionality
- dark content cards
- clear enabled/disabled state
- cyan/lila hover/focus styling

### Settings
- grouped settings sections
- redesigned toggles, selectors, path fields, and Java/runtime controls
- avoid Windows-default-looking controls where practical

### Account
- preserve official Microsoft OAuth flow
- show Microsoft connection state and Minecraft profile state distinctly
- show real Minecraft in-game name after verification
- approval/403 state must remain clearly explained and must not be bypassed

### Shop / Cosmetics
The shop should visually support the VELTRIX cosmetics system.

Initial highlighted cosmetic families:
- VELTRIX Cape
- VELTRIX Wings / Elytra cosmetic
- VELTRIX Shield cosmetic
- VELTRIX Pet

The shield concept specifically represents a cosmetic skin for the normal Minecraft shield held in the offhand, not a separate fantasy shield item.

The shop can remain a visual/storefront layer if backend purchase functionality is not yet available; it must not fake successful purchases.

### News
- keep data-driven news behavior where possible
- new dark editorial cards
- image, category, date, title, summary, read-more treatment
- match website news styling

### Support
- Support must open the official Discord invite:
  `https://discord.gg/9qYaVP6jvp`
- it must not send the user back to the GitHub repository

## Loading / startup screen
- new V logo centered prominently
- black/anthracite background
- cyan glow entering from left, purple from right
- simple loading/progress treatment
- startup-resilience logging and global exception handling from 0.8.2 must remain intact

## Installer and Windows packaging
Official installer output:
- `VELTRIX-Setup-0.8.3.exe`

Installer requirements:
- Java 21 bundled runtime
- `jdk.crypto.ec` retained
- per-user Windows installation
- Start Menu shortcut
- desktop shortcut
- new supplied V logo converted to Windows `.ico`
- installer/application version reports 0.8.3 consistently

Release gate:
- installer must install silently in CI
- installed executable must pass `--diagnose`
- installed GUI must report completed startup and remain running during smoke test
- malformed persisted settings regression remains covered

## Website integration
After the 0.8.3 installer is verified:
- website Download for Windows links to the 0.8.3 release asset
- macOS displays `Coming Soon`
- Linux displays `Coming Soon`
- Windows/macOS/Linux use recognizable platform icons
- Support links to Discord
- launcher preview uses a real screenshot/render of the actual 0.8.3 launcher, not an unrelated mockup
- site design should mirror the same cyan-left / purple-right identity

## Compatibility and non-goals
The redesign must not intentionally alter:
- Microsoft Entra application ID behavior
- official Microsoft OAuth PKCE flow
- Xbox Live / XSTS / Minecraft Services flow
- Minecraft ownership checks
- Minecraft profile retrieval
- Minecraft launch coordinator
- Fabric launch support
- version manifest handling
- Java runtime detection
- startup diagnostics and crash logging

No bypasses are permitted for the current Minecraft Services allowlisting / `Invalid app registration` issue.

## Testing requirements
Before release:
1. compile complete launcher on Java 21
2. run existing unit/regression checks
3. verify required launcher classes exist
4. verify startup diagnostics references LocalAppData startup logs
5. verify malformed settings recovery
6. verify `jdk.crypto.ec` runtime module
7. build Windows installer
8. install installer in GitHub Actions Windows runner
9. run installed `--diagnose`
10. launch installed GUI and verify startup completion
11. verify website download URL matches the published 0.8.3 asset
12. verify Support points to Discord

## Release result
A successful completion produces:
- GitHub release/tag `v0.8.3`
- `VELTRIX-Setup-0.8.3.exe`
- updated GitHub Pages site
- new logo used by launcher, installer, shortcut, and website
- website preview that matches the real 0.8.3 launcher

## Success criteria
VELTRIX 0.8.3 is successful when a user can download the Windows installer from the official site, install it, open the redesigned launcher, see the new cyan-left / purple-right VELTRIX identity consistently throughout the client, and use the same core login/launch functionality as before without regressions introduced by the redesign.
