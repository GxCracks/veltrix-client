VELTRIX Client

Privacy & authentication

VELTRIX is an independent Minecraft Java launcher project. It is not affiliated with or endorsed by Mojang Studios or Microsoft.

Microsoft sign-in

The launcher is designed to use the official Microsoft OAuth flow and Minecraft Services for identity and ownership checks. VELTRIX does not ask for or store your Microsoft password. The VELTRIX application registration is still awaiting Minecraft Services approval, so Minecraft authentication may return an app-registration error until Microsoft/Mojang approves the application.

Local launcher data

Launcher preferences, instances and startup diagnostic logs may be stored locally on the computer. Startup logs are used to diagnose launcher failures.

No cracked bypass

The project does not use an offline/cracked login bypass or another application's client ID to circumvent Minecraft Services approval.

Website

This public project website is static. It does not provide a password form for Microsoft accounts. Downloads are served through the project's GitHub release page.
