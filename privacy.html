PRIVACY

VELTRIX Client privacy notice.

VELTRIX is an independent launcher project. This page describes the intended privacy and security approach for the current public development project.

Authentication

VELTRIX is designed to use Microsoft OAuth 2.0 with PKCE in the user's system browser. Users should not enter their Microsoft password directly into VELTRIX.

Account data

When Minecraft authentication is available, VELTRIX may process profile information such as the Minecraft profile name, UUID and session state needed to launch the game.

Tokens

Access tokens and similar credentials are intended only for authentication and session handling. They should not be displayed in the normal UI or written to general launcher logs.

Local launcher files

VELTRIX may store launcher settings, instance configuration, downloaded Minecraft metadata and game-related files locally on the user's device.

Analytics

This static project website does not use analytics or advertising trackers in its current form.

Independent project notice

VELTRIX is not affiliated with, endorsed by, or sponsored by Mojang Studios or Microsoft.
